# Vael – Kriegsführung und Philosophie

**Philosophie:** Wirtschaftlicher Erfolg schafft Sicherheit.  
**Kriegsführung:** Krieg als Geschäft. Effizienz über Menschen.  
**Preis:** Der menschliche Preis. Wohlstand wird akzeptiert, solange er real ist.

Manche Bürger und Manager tragen das System mit, weil sie glauben, dass wirtschaftlicher Erfolg Sicherheit schafft. Der Preis wird akzeptiert, solange der Wohlstand real ist.

**Interne Spannungen:**
- Konzerne, die Profit maximieren.
- Arbeiter und Soldaten, die den Preis zahlen.
- Manager, die den Krieg als Markt sehen und ihn gleichzeitig fürchten.
