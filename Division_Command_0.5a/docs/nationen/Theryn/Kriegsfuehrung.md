# Theryn – Kriegsführung und Philosophie

**Philosophie:** Der Glaube gibt Sinn. Opfer können heilig sein.  
**Kriegsführung:** Geschuldete Pflicht. Einschränkungen durch religiöse Gebote.  
**Preis:** Der Glaube verlangt. Der Krieg bleibt negativ, das Opfer kann als heilig empfunden werden.

Viele Gläubige tragen die Pflicht mit Pathos, weil sie glauben, dass der Glaube Sinn gibt. Der Krieg bleibt negativ, aber das Opfer kann als heilig empfunden werden.

**Interne Spannungen:**
- Orthodoxe, die Opfer als heilig sehen.
- Pragmatiker, die den Glauben als Werkzeug nutzen.
- Gläubige, die den Krieg verabscheuen und trotzdem kämpfen.
