# Vesper – Kriegsführung und Philosophie

**Philosophie:** Ein System ohne persönliche Gefolgschaft ist fairer als persönliche Herrschaft.  
**Kriegsführung:** Scheinschwerpunkt und Überwachung.  
**Preis:** Vertrauen. Das System funktioniert, solange es getragen wird.

Manche Bürger tragen das System mit, weil sie glauben, dass Überwachung ohne persönliche Gefolgschaft fairer ist als persönliche Herrschaft. Andere sehen darin nur Kontrolle.

**Interne Spannungen:**
- Systemtreue, die die Überwachung als Schutz sehen.
- Dissidenten, die sie fürchten.
- Soldaten, die den Schein tragen und die Wahrheit kennen.
