# Vesper – System

**Bindung:** System  
**Stärke durch Opfer:** Scheinschwerpunkt und Überwachung ohne Gefolgschaft. Der Preis ist das Vertrauen.

## Philosophie
Ein System ohne persönliche Gefolgschaft ist fairer als persönliche Herrschaft. Manche Bürger tragen das System mit, weil sie glauben, dass Überwachung ohne persönliche Bindung fairer und stabiler ist. Andere sehen darin nur Kontrolle. Das System funktioniert, solange es getragen wird. Das Tragen ist kein Zwang, sondern die Bedingung dafür, dass es funktioniert.

## Kriegsführung
Scheinschwerpunkt und Überwachung. Das System funktioniert, solange es getragen wird. Die Politik rechtfertigt die Überwachung mit dem Argument, dass ein System ohne persönliche Gefolgschaft weniger anfällig für Korruption ist. Der Schein ist kein Betrug, sondern die Bedingung dafür, dass das System nicht an einer Person hängt.

## Preis
Vertrauen. Das System funktioniert, solange es getragen wird. Der Preis ist bekannt. Er wird getragen, weil die Alternative schlimmer ist.

## Interne Strömungen
- Systemtreue, die die Überwachung als Schutz sehen und sie mit Überzeugung tragen. Für sie ist das System keine Kontrolle, sondern die Bedingung für Fairness.
- Dissidenten, die sie fürchten. Sie sehen die Überwachung und fragen, was vom Vertrauen übrig bleibt.
- Soldaten, die den Schein tragen und die Wahrheit kennen – manche sehen darin Notwendigkeit, andere Verrat. Sie tragen den Schein und die Frage gleichzeitig.

## Alltag
Familien erzählen vom System als Schutz und als Misstrauen. Ein Elternteil, das dem System vertraut, und ein Kind, das es fürchtet, können am selben Tisch sitzen. Kinder lernen, dass gesehen zu werden normal ist – und dass Vertrauen anders funktioniert.

**Hoffnung:** Dass das System hält.  
**Angst:** Dass das Vertrauen verloren geht.  
**Tabu:** Die Überwachung öffentlich als Verrat zu bezeichnen.

## Leitfrage
Wie lange hält ein System, das nicht getragen wird?

## Anwendung auf Karten
Karten können Schein und Überwachung zeigen. Manche betonen die Fairness des Systems, andere den Verlust von Vertrauen. Der Pathos derer, die das System tragen, und die Frage derer, die es fürchten, sollen spürbar sein.
