# Averon – Insignien und Platzierungen

**Kernsymbol:** Offenes Auge + Datenstreifen

## Platzierungen
- Stirnband / Kragen: Offenes Auge
- Brust: Datenstreifen-Orden
- Schulter: Kleine Sensor-Symbole

## Rang-Varianten
- Fähnrich: Einfaches Auge
- Höhere Ränge: Mehr Datenlinien, leuchtende Akzente
- Generalfeldmarschall: Vollständig sichtbares, überwachendes Auge

Moderne, klare Formen. Dunkelgrün / Olive mit hellen Datenlinien.
