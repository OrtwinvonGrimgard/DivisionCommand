# Vesper – Ränge und Altersstufen

**Bindung:** System  
**Stärke durch Opfer:** Scheinschwerpunkt und Überwachung ohne Gefolgschaft. Der Preis ist das Vertrauen.

Rangaufstieg bedeutet mehr Verantwortung für das System und die Überwachung.

## Ränge

### Fähnrich (17–21)
Junges Systemträger. Trägt die ersten Scheine. Gesicht offen, Uniform mit System-Symbolen.

### Oberfähnrich (20–23)
Erste eigene Überwachungen. Lernt den Preis des Vertrauens.

### Leutnant (21–26)
Eigener Zug. Das System wird konkret.

### Oberleutnant (26–32)
Stellvertreter. Beginnt, den Schein an andere weiterzugeben.

### Hauptmann (32–38)
Kompaniechef. Entscheidet über die Scheinschwerpunkte. Mehr Orden.

### Stabshauptmann (36–42)
Stab. Plant die Überwachung.

### Major (38–44)
Bataillon. Das System wird institutionell.

### Oberstleutnant (44–50)
Regiment. Stark im System.

### Oberst (50–56)
Regimentskommandeur. Das System spricht durch ihn.

### Brigadegeneral (56–62)
Brigade. Trägt das System für viele.

### Generalmajor (62–68)
Division. Entscheidet über große Scheinoperationen.

### Generalleutnant (68–74)
Korps. Nur wenige. Der Preis des Vertrauens ist extrem.

### General (74–80)
Armee. Das System spricht durch ihn.

### Generaloberst (78–85)
Strategisch. Extrem selten. Lebt für das System.

### Feldmarschall (82–90)
Lebender Beweis, dass Überwachung ohne Gefolgschaft fairer ist.

### Generalfeldmarschall (legendär)
Kaum erreichbar. Wenn vorhanden, ist er das Symbol des Systems. Gesicht alt, aber unpersönlich.

**Interne Spannung:** Systemtreue sehen den Aufstieg als Schutz. Viele Dissidenten sehen den Preis. Je höher, desto stärker die Verantwortung für das System.
