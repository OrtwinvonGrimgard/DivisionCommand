# Karsk – Insignien und Platzierungen

**Kernsymbol:** Hexagon mit eingebettetem Auge / Implantat

## Platzierungen
- Kragen: Hexagon-Auge
- Oberarm: Technische Streifen + Hexagon
- Brust: Größeres Implantat-Symbol

## Rang-Varianten
- Fähnrich: Einfaches Hexagon
- Höhere Ränge: Mehr Schaltkreise, größere Implantate, metallische Akzente
- Generalfeldmarschall: Vollständig integriertes System-Auge

Kühle, technische Formen. Anthrazit, Silber, dunkles Metall. Keine organischen Symbole.
